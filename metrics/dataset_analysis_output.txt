第 1 部分｜动作空间语义：action 到底是什么
==============================================================================

  state 前两维（agent_pos）范围: x=[13.5, 496.1]  y=[32.9, 511.0]
  action                   范围: x=[12.0, 511.0]  y=[25.0, 511.0]

  corr(agent_pos, block_pos) = (+0.651, +0.587)

  相邻两步末端实际位移      中位数 =   7.89 像素
  |action − 当前位置|       中位数 =  19.33 像素

  → action 是末端执行器的目标位置（绝对坐标），不是位移。
      它比当前位置向前看约一个步长的量级，相当于「提前量」。
      因此 action 与 state[:2] 高度相关，预测任务本质上是
      「根据当前局面决定下一步把末端开到哪里」。

==============================================================================
第 2 部分｜状态空间覆盖：朴素回归的「外推」压力有多大
==============================================================================

  做法：随机抽若干锚点，统计标准化 5 维状态下、半径 r 以内
        来自**其他轨迹**的样本数（排除同轨迹样本，否则取到的是
        时间上相邻的近邻，不构成有意义的状态重叠）。

      半径 r |       邻居数中位数 |         邻居<5 的锚点占比
  -------- | ------------ | ------------------
      0.05 |            0 |              98.1%
      0.10 |            0 |              88.6%
      0.20 |            0 |              64.1%
      0.30 |            6 |              46.3%
      0.50 |           59 |              23.3%

  → 解读：半径越小，绝大多数位置在整个数据集里越接近「孤例」。
     这意味着基于近邻/查表的回归器几乎处处需要外推，
     而神经网络的外推能力很差 —— 这是 covariate shift 的量化表现。

==============================================================================
第 3 部分｜邻域动作一致性：状态层面是否存在多模态
==============================================================================

  做法：对每个锚点，取半径 r 内来自其他轨迹的近邻动作 A，计算
           ① 邻域内典型间距 d_1nn = 每个动作到它最近邻居的平均距离
           ② MSE 最优预测（= 条件均值）离最近真实动作的距离 d_pred

        主判据 ratio = d_pred / d_1nn，在多个半径下都测，看结论是否一致：
          单一紧密动作簇 → 均值落在簇内   → d_pred ≈ d_1nn → ratio ≈ 1
          多个分离动作簇 → 均值落在簇间空地 → d_pred >> d_1nn → ratio >> 1

      半径 r |     有效锚点 |    d_1nn |   d_pred |   ratio
  -------- | -------- | -------- | -------- | -------
      0.15 |      250 |     2.73 |     1.88 |    0.69
      0.30 |      683 |     3.75 |     2.87 |    0.77

  各半径下 ratio 的最大值 = 0.77

  → 所有半径下动作都接近单峰：条件均值稳定落在真实动作的密集区。
     → 对 PushT，多模态不是主要矛盾（但见下方保留意见）。

  具体例子（半径 0.15，共 147 个近邻；单位：像素）
    状态（标准化）: [ 0.461 -0.494  0.246 -0.289 -0.601]
    ── 离条件均值最近的 3 个真实动作 ──
      距离  0.89 : (  271.0,   247.0)
      距离  1.53 : (  273.0,   248.0)
      距离  1.53 : (  273.0,   248.0)
    ── 条件均值（MSE 的最优解）──
                  (  271.9,   247.0)
    ── 离条件均值最远的 3 个真实动作 ──
      距离 31.88 : (  303.0,   240.0)
      距离 33.25 : (  301.0,   263.0)
      距离 57.54 : (  329.0,   240.0)

  ⚠ 保留意见：本检验以**完整 5 维状态**（含末端精确坐标 + 块位姿）为条件，
     这比策略实际可见的信息**更充分**（策略看到的是 96×96 图像 + 末端坐标）。
     条件化在更少信息上，歧义只会更大。故本结果是「任务确定性」的上界，
     不能据此完全排除多模态。

==============================================================================
结论
==============================================================================

  朴素单步 MSE 回归在 PushT 上的主要障碍，**不是**多模态（第 3 部分
  测出的比值偏小，说明状态层面的动作分布相当接近单峰），而是：

  · 状态空间覆盖极稀疏（第 2 部分）→ 测试时几乎处处需要外推
  · 单步预测意味着每次小误差都会立刻反馈进下一步 → 误差累积

  这正对应 ACT / Diffusion Policy 的核心设计：**一次预测多步动作**，
  把重规划频率从「每步一次」降到「每 N 步一次」，
  从而大幅降低 covariate shift 的发作频率。
